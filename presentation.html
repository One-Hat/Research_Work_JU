1. The Problem Space

Why Single Vision Models Plateau

CNNs and Vision Transformers excel at fundamentally different spatial representations. Neither architecture is universally optimal across all semantic categories.

Convolutional Branch (VGG-BN)
  • Inductive Bias: Compact local receptive fields, spatial translation equivariance.
  • Strengths: Superb extraction of fine-grained textures, boundaries, low data hunger.
  • Inherent Flaw: Blind to long-range context without deep stacks of downsampling; rigid spatial priors.
  • Target Accuracy: ~92%–94% on CIFAR-10.
Vision Transformer (ViT)
  • Inductive Bias: All-to-all patch self-attention across 64 patches ($4 \times 4$).
  • Strengths: Dynamic global relationship routing, flexible long-range geometric associations.
  • Inherent Flaw: Lacks built-in 2D spatial locality; requires large datasets or careful tuning on small images.
  • Target Accuracy: ~88%–91% on CIFAR-10.
💡 Core Research Question: Can we learn a continuous arbitration policy that dynamically shifts weight to the stronger model for each class and instance?

3. Theoretical Rationale

Why Standard Ensembling & Bandits Fail

We evaluated standard ensembling and bandit algorithms in simulation and rejected them for fundamental mathematical shortcomings.

❌ Naive 50/50 Ensemble
  • Static Prior: Assumes both models are equally skilled on all semantic classes.
  • Failure Mode: When CNN is 94% on textures but ViT is 75%, a fixed 50/50 mix drags down the accurate branch.
  • Lacks Adaptability: Zero context awareness.
❌ Multiplicative Weights (Hedge)
  • Update Rule: $w_t \propto w_{t-1} e^{\eta r_t}$ with constant learning rate $\eta$.
  • Failure Mode: Martingale in log-odds space with no mean reversion.
  • Random Walk: Even under equal true skill, it inevitably drifts to extreme weights ($0.0$ or $1.0$) purely from noise.
❌ Classic Bandit UCB
  • Mismatched Setting: UCB arm-selection assumes partial feedback (only chosen arm is observed).
  • Our Setting: Both branches output full softmax probabilities simultaneously (full information).
  • Our Adaptation: We repurpose UCB's $1/\sqrt{n}$ uncertainty insight into a confidence shrinkage regularizer.
Robbins-Monro Condition: Step size αₙ = 1/n (exact running sample mean) guarantees asymptotic convergence under stationary model skill!

5. Test-Time Protocol

Two-Pass Contextual Proxy State Inference

At inference, the true label $y$ is unknown. We resolve this chicken-and-egg problem using a fast two-pass proxy consensus mechanism.

Pass 1: Rough Consensus
Compute an unweighted average of class probabilities:
ŷ₀ = argmax(0.5 · P_cnn + 0.5 · P_vit)
This provisional class index $\hat{y}_0$ acts as our proxy contextual state $s$.
Pass 2: Confidence Verification
Look up calibrated weight $w[\hat{y}_0]$. Verify calibration confidence:
if c[ŷ₀] < 0.3 ➔ Fallback
If calibration had sparse observations for state $\hat{y}_0$, fall back to global pooled weights $(w_c^{\text{global}}, w_v^{\text{global}})$.
Pass 3: Final Fused Decision
Apply calibrated contextual weights to original probabilities:
ŷ = argmax(w_c[ŷ₀]·P_c + w_v[ŷ₀]·P_v)
Produces final prediction with zero additional model forward passes!
⚡ Computational Overhead: The entire two-pass arbitration is an O(1) table lookup requiring < 0.05 ms per sample.
6. Empirical Validation

Strict 4-Way Splitting & Multi-Metric Evaluation

To withstand peer review scrutiny and eliminate data leakage, we enforce an airtight 4-way partition on CIFAR-10.

🛡️ Data-Split Partitioning (Seed = 42)
  • Train Set (40,000): Gradients & weight updates with random crop/flip augmentations.
  • Monitor Set (5,000): Unaugmented validation set for epoch tracking & saving best_checkpoint.pt.
  • RL Val Set (5,000): Completely isolated during training. Reserved strictly for calibrating the RL weights.
  • Test Set (10,000): Official CIFAR-10 test set evaluated exactly once for final reported benchmarks.
📊 Multi-Metric Evaluation Suite
  • Accuracy & Macro-F1: Equal weighting across all 10 classes to evaluate balanced generalization.
  • Macro-Precision & Recall: Detailed false-positive vs false-negative profiling.
  • Per-Class Breakdown: Granular F1 deltas vs best single branch (revealing where CNN vs ViT dominate).
  • Normalized Confusion Matrix: Heatmap quantifying class recall and misclassification corridors.
Zero Leakage Guarantee: The RL calibration module never observes training or test samples.
