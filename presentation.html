01 — Problem Space

Why Single Models Hit a Ceiling

CNNs and Vision Transformers encode fundamentally different spatial priors. Neither consistently dominates across all semantic categories.

🔲
VGG-BN Branch (CNN)
  • 7 conv layers with 3×3 local receptive fields
  • Translation equivariance → strong on textures & edges
  • Blind to long-range spatial relationships
  • ~2.4M parameters | Expected: 92–94%
🌐
ViT Branch (Transformer)
  • 6-layer, 4-head self-attention across 64 patches
  • All-to-all routing → captures global context
  • No built-in 2D locality → trained from scratch on 32×32
  • ~1.2M parameters | Test Accuracy: 79.54%
Question: Can we learn wcnn[s] per class s, routing each image to the better-skilled branch?

03 — Theoretical Rationale

Why Standard Approaches Fail

We evaluated three standard fusion strategies in controlled simulation and rejected each for fundamental mathematical reasons.

Method Core Mechanism Failure Mode Verdict
Naive 50/50 Fixed equal weighting for all classes Drags down the stronger branch; zero context awareness Rejected
Hedge / MW w ← w · eηr with constant η Martingale random walk → drifts to 0 or 1 from noise Rejected
UCB Arm-Select Explore-exploit arm selection via upper confidence bound Assumes partial feedback; we observe both models fully Adapted
Ours: RL Fusion Sample-mean advantage + UCB shrinkage + sigmoid link Provably converges (Robbins-Monro); bounded weights ✓ Adopted
Key Insight: αn = 1/n guarantees ΣΣ α = ∞, Σ α² < ∞ → asymptotic convergence under stationary model skill.
04 — Mathematical Formulation

The Update Rule in Detail

Three interconnected components govern the per-class fusion weight:

Δ
1. Advantage Estimation
ΔQ[s] = Q_cnn[s] − Q_vit[s]
Running sample mean of bounded rewards r = 2·p(y) − 1 for each model, updated incrementally via Robbins-Monro (α = 1/n).
c
2. Confidence Shrinkage
c[s] = min(1.0, n[s] / n₀)
Inspired by UCB's uncertainty decay. Low-sample classes are regularized back toward the neutral prior (w = 0.50), preventing overfitting on early observations.
σ
3. Sigmoid Saturation
w_cnn[s] = 0.05 + 0.90 · σ(k·ΔQ·c)
Unlike log(x) which is unbounded, σ(·) has true horizontal asymptotes, strictly enforcing w ∈ [0.05, 0.95] regardless of advantage magnitude.
w_cnn[s] = w_min + (w_max − w_min) · σ( k · (Q_cnn[s] − Q_vit[s]) · min(1, n[s]/n₀) )

06 — Inference Protocol

Two-Pass Proxy State at Test Time

During inference the true label y is unknown. We resolve this with a two-pass consensus mechanism.

1
Rough Consensus
ŷ₀ = argmax(0.5·P_c + 0.5·P_v)
2
Confidence Check
If c[ŷ₀] < 0.3 → fall back to global weight
3
Contextual Lookup
w_cnn[ŷ₀], w_vit[ŷ₀] from calibrated table
4
Final Decision
ŷ = argmax(w_c·P_c + w_v·P_v)
💡 Why This Works
  • When both models agree, the proxy state matches the true class with very high probability
  • When they disagree, the contextual weight tilts toward the historically stronger branch for that class
  • Low-confidence states safely degrade to the global average — never worse than naive ensemble
⚡ Computational Overhead
  • Zero additional neural network forward passes
  • The entire arbitration is an O(1) table lookup
  • Adds < 0.05 ms latency per sample
  • Smaller than a single attention head computation
